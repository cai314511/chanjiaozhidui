# 本地语音与交互

蓝金液态玻璃界面支持菜单胶囊滑动、鼠标局部光影和最大4度倾斜、模块展开及底部缩略条、Alt+空格命令搜索。Windows 可能优先处理该快捷键，右上角搜索按钮提供同一入口。系统开启减少动态效果时暂停装饰动画。

语音识别使用已缓存的 Whisper base，通过 faster-whisper 在本机 CPU、INT8 运行。默认读取用户缓存目录；也可设置 `CHZ_WHISPER_MODEL` 指向含 model.bin/config.json/tokenizer.json 的完整模型目录。运行时使用 local_files_only，不自动下载模型。合成使用 Windows 本地中文 Huihui SAPI 组件，不调用浏览器云端语音。模型需遵循 [faster-whisper 官方说明](https://github.com/SYSTRAN/faster-whisper) 与原模型许可；[Windows SAPI 文档](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ms723602(v=vs.85))说明本地语音输出能力。OpenCC 将识别结果转换为简体中文。

录音通过麦克风音量驱动水滴变化，每约4.5秒识别一段，结果显示在可编辑文本框。单次接口最多90秒、12MB。普通语音输入最长60秒。CPU 首次加载和中文识别会产生延迟；短片段的转写需要核对。离开页面、关闭对话、退出账号或隐藏页面会停止录音；面试播报时暂停麦克风，避免回声被再次识别。

AI面试将明确确认的转写交给 DeepSeek，音频识别和合成仍在本机完成。企业预设问题按顺序推进。真人面试使用双方已授权投递的会话，以 WebRTC 连接音频，HTTP 信令按 call_id 隔离通话轮次；撤回后拒绝访问。当前仅监听 localhost，可供同机双方预览；跨设备使用需要另行配置可信 HTTPS 和网络可达性，系统未配置外部 STUN/TURN，也没有宣称完成跨公网真人通话验收。连接机制参考 [WebRTC 官方说明](https://webrtc.org/getting-started/peer-connections)。

文档与作品默认私有。投递时选择文档、作品的授权范围，企业只能读取相应授权内容。视频供播放及人工复核，未使用文本模型宣称理解视频画面。网站正文通过固定公网地址连接和 TLS 主机验证导入，拒绝内网地址、非HTTPS、凭证和非标准端口。

普通匹配及 Agent 响应只展示总体匹配结果与材料建议，公式、数值权重、逐项贡献和敏感性留在后台。运维人员在项目文档和正式测试中仍可检查数学模型。
