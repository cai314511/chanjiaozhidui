# 本地语音与交互

绿松石与暖金液态玻璃界面支持菜单胶囊滑动、鼠标局部光影和最大4度倾斜、模块展开及底部缩略条、Alt+空格命令搜索。正文与表单采用深色文字，玻璃边缘采用暖金色。Windows 可能优先处理该快捷键，右上角搜索按钮提供同一入口。系统开启减少动态效果时暂停装饰动画。

语音识别支持本地 SenseVoiceSmall 与 faster-whisper。`CHZ_ASR_MODEL` 设置模型目录，相对路径以项目根目录为准；从进程环境或项目 `.env` 读取，进程环境优先，并兼容旧变量 `CHZ_WHISPER_MODEL`。未配置时，优先使用项目中已存在的 `models/SenseVoiceSmall`，该目录不存在时读取原 Whisper base 缓存。显式配置错误或已存在的 SenseVoice 目录不完整会报告缺项，不暗中换模型。

安装基础依赖后，SenseVoice 另需 `python -m pip install -r requirements-sensevoice.txt`。本地目录包含 `model.pt`、`config.yaml`、`configuration.json`、`tokens.json`、`chn_jpn_yue_eng_ko_spectok.bpe.model` 与 `am.mvn`。模型通过 FunASR 在 CPU 上加载，关闭更新检查及远程代码执行，不配置需要另行下载的 VAD 模型；接口先用 PyAV 解码到16kHz单声道数组，再传给模型，无需系统 ffmpeg 命令。30秒以上音频顺序分段，每段使用独立 cache；语言自动识别，去除语言、情感、事件控制标签，仅将文字填回表单。Windows 中文路径通过读取原 SentencePiece 模型字节适配，不修改权重或词表。首次请求包含 Python 推理库导入及权重加载，后续请求复用同一模型；修改模型配置后应重启服务。

Whisper 目录包含 `model.bin/config.json/tokenizer.json`，沿用 CPU INT8、`local_files_only=True`；运行时不自动下载。模型文件受 `.gitignore` 排除，更新 GitHub 代码不会替服务器安装依赖或复制权重。状态接口返回实际模型名称、文件及依赖是否具备（`recognition_ready`）、是否完成加载（`recognition_loaded`）及配置错误；模型加载或识别失败返回503，不伪造转写成功。

合成使用 Windows 本地中文 Huihui SAPI 组件，不调用浏览器云端语音。模型需遵循 [SenseVoice 官方模型卡及许可](https://huggingface.co/FunAudioLLM/SenseVoiceSmall)、[faster-whisper 官方说明](https://github.com/SYSTRAN/faster-whisper)；[Windows SAPI 文档](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ms723602(v=vs.85))说明本地语音输出能力。OpenCC 将识别结果转换为简体中文。

麦克风与播放音频的实际音量驱动水滴变化。访谈和普通表单均支持滚动转写：每约1.4秒尝试识别当前累计音频，同一时刻仅执行一项识别；临时文字单独显示，停顿或停止后将完整片段确认到可编辑输入框。持续讲话每18秒划分一段，识别过程中下一段继续采集。单次接口最多90秒、12MB，普通语音输入最长60秒。实际文字延迟取决于本机CPU与模型加载时间。离开页面、关闭对话、退出账号会取消录音与待回填结果；隐藏页面停止录音；面试播报时暂停麦克风。

AI面试将明确确认的转写交给 DeepSeek，音频识别和合成仍在本机完成。企业预设问题按顺序推进。真人面试使用双方已授权投递的会话，以 WebRTC 连接音频，HTTP 信令按 call_id 隔离通话轮次；撤回后拒绝访问。当前仅监听 localhost，可供同机双方预览；跨设备使用需要另行配置可信 HTTPS 和网络可达性，系统未配置外部 STUN/TURN，也没有宣称完成跨公网真人通话验收。连接机制参考 [WebRTC 官方说明](https://webrtc.org/getting-started/peer-connections)。

文档与作品默认私有。投递时选择文档、作品的授权范围，企业只能读取相应授权内容。视频供播放及人工复核，未使用文本模型宣称理解视频画面。网站正文通过固定公网地址连接和 TLS 主机验证导入，拒绝内网地址、非HTTPS、凭证和非标准端口。

普通匹配及 Agent 响应只展示总体匹配结果与材料建议，公式、数值权重、逐项贡献和敏感性留在后台。运维人员在项目文档和正式测试中仍可检查数学模型。
