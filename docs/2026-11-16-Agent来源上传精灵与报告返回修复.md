# Agent 数据来源、文件上传、精灵与报告返回修复

## 已修复

1. 高校报告页的角色精灵曾被专用 CSS 隐藏，改为“AI”文字。现已取消该替换，保留原透明角色图集；报告右侧留出精灵所需空间。浏览器逐一遍历学生、企业、高校导航中的功能页，验证图片入口可见、位于视口内且未被覆盖。
2. 企业助手通用入口原先只有文档上下文，无法读取页面已经存在的岗位和投递统计。新增服务端 `recruitment` 来源，按当前企业归属统计岗位和未撤回投递，不发送其他企业数据，不把投递记录数称为去重人数。面板增加岗位范围及测评对象选择；聊天读取招聘概况，岗位模式读取选定岗位，测评读取选定且仍有效的授权投递。其他企业岗位返回 403，候选人与岗位不一致时拒绝请求；历史记录和追问同样复核岗位访问范围。
3. 三端输入区均增加“＋”上传入口，复用现有 TXT、MD、CSV、DOCX、PDF、XLSX 提取接口。单文件上限12MB，一次最多选择5份。上传后显示附件、正文查看和移除按钮；正文授权不自动勾选，未确认时阻止发送。上传失败明确提示，关闭面板停止本次等待。重新打开可恢复所选附件，但重新确认发送授权。用户限定只依据文件时，模型指引要求仅读取文档来源；真实测试核对了工具调用记录。
4. 报告导出不再打开并改写空白文档，而是打开固定地址 `/assets/report-preview.html`。预览顶部固定展示“返回诊断报告”“打印 / 另存为 PDF”“保存独立 HTML”。返回按钮关闭预览并聚焦原工作空间；打印按钮不导航，打印完成或取消均保留报告页。继续使用 CSP、CSSOM、静态图表及固定情景快照，未放宽内联脚本策略。

## 回复格式故障处理

真实验收中曾出现一次模型结构校验失败。新增最终回复格式修正：仅允许模型修正一次 JSON／草稿结构，仍受原有六轮与180秒总时限约束；不能为通过校验而补造资料。第二次仍失败则明确报错，不产生可填写草稿。该分支用明确的故障替身验证，不将故障模拟称为真实模型成功恢复。
