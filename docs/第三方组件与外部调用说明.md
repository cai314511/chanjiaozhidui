## 外网API报备信息草案

服务：DeepSeek。域名：api.deepseek.com。接口：POST /chat/completions。默认模型：deepseek-flash。用途：授权资料抽取、岗位和个人画像草稿、测评辅助和结果解释。密钥保留在服务端本地配置，不进入前端和提交材料。

发送内容：用户主动提交的问题、其授权的画像或投递资料、额外勾选的正文，以及服务端工具返回的必要信息。发送前执行已知身份泛化及规则检查，返回后检查标识并要求人工复核。不能承诺规则扫描能识别全部个人信息或代替事实与伦理审核。

专业调整、约束求解、统计与情景推演均在本地执行。公开演示模式关闭助手入口；外网联调完成前使用本地引擎当场推演。

语音识别使用本地 faster-whisper 1.2.0 和缓存的 Whisper base 模型；语音合成使用 Windows 中文 SAPI 组件。OpenCC 0.1.7 负责简繁转换。音频处理不调用云端语音服务；AI访谈经确认的转写使用 DeepSeek。个人网站提取另使用 BeautifulSoup 与 urllib3，固定公网连接并验证TLS主机名。相应依赖与模型均需保留安装包内的许可证和署名。

本文件是报备准备信息，尚未向主办方发送，不能视为已取得现场外网使用许可。
