# 学生首页企业 Logo 与岗位检查

## 修改范围

补齐默认首页前 20 家资料企业的全部标识；企业端自行添加的企业保持原资料。新增 8 个品牌、覆盖 11 家企业：AOS、阿斯利康、BAC、必维的四个上海实体、CBC、CSA Group、EDG、Inditex。

资源本地保存、同源读取，保持原比例。修复竖版 Logo 在 Grid 内按固有高度撑出容器、遮住下方文字的问题。CBC 仅提取来源图上方的共用品牌，移除“泉州分公司”副标题；CSA、必维去除外围留白。阿斯利康采用官方招聘站紫金字标。没有重绘标识。

来源清单：`Assets/company-logos/verified-sources-20261115.json`，注册表保存来源地址、企业关系说明和图片校验值。CBC 来自智联招聘企业资料，CSA 来自 SunSpec 联盟会员页，其余来自企业官网、官方招聘站或 Riot 官方赛事页面。第三方来源如实记录，没有冒称企业官网直供。

## 岗位处理

20 家企业全部已有本地历史招聘资料，无需编造、无需修改业务数据库。企业卡片展示最多两个已收录岗位标题及历史公告数量；有平台有效岗位时另外显示在招数量。历史岗位保留原职责、城市、发布日期与出处，可通过“查看企业”展开查看。

截图涉及的示例：必维运营行政助理、工程项目协调助理、Coordinator_协调员、Non ECE FV Project Engineer、海外自动驾驶认证工程师；CBC 银行回款专员、信控岗；CSA 电池及储能系统认证工程师。它们均来自原本收录的本地数据。

“平台岗位为 0”的原因是这些企业没有在本平台发布有效职位；历史公告没有转换成当前企业发布，也没有生成可以假投递的岗位。

## 验证

- `tests/test_market.py`、`tests/test_company_logos.py`、`tests/test_company_logo_browser.py`、`tests/test_discovery_browser.py`：22 项通过，含无新增岗位、注册表覆盖及竖版图像边界回归。
- 使用本地真实公开市场目录、隔离数据库及新建测试学生账号，在 Edge 的 1440×900 和 390×844 下逐一检查前 20 家企业：每个图片端点返回 200，每张图片能够解码、保持 contain 比例、完整位于容器内；页面无横向溢出、无 JavaScript 异常；卡片显示本地岗位标题，CSA 详情显示原岗位。
- 本地记录：`runtime/company-refresh/acceptance.json`；截图 `desktop.png`、`mobile.png`；全量已核验品牌联系表 `logos-final.png`。
- 全目录审计：27,231 个企业 ID；41 个已核验 ID、33 张独立品牌图。任务只保证本次首页范围，全目录其余 27,190 家仍在原待核验队列。
