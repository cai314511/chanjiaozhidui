# 三端 Agent 与企业商标验收

本地预览：http://127.0.0.1:8765/ 。本次仅本地实现，未提交、推送或部署。保留现有用户数据和此前高校端变更。

## 已实现

学生、企业、高校的悬浮助手顶部共用 Three.js 水滴，具有透明折射、柔和高光、缓慢不规则摇晃与低饱和环境光。录音响应音量；转写可编辑，确认提交后显示思考状态；成功恢复待机，失败结束等待。原语音讲述入口保留，助手没有新增自动语音播报。

关闭助手会停止捕获、取消客户端等待并释放渲染；退出身份和页面导航同样清理。页面隐藏停止助手录音并暂停水滴，支持减少动态效果和无WebGL时静态降级。资料选择、正文发送确认与服务端权限沿用原规则。

企业商标使用本地PNG，存于Assets/company-logos。全目录27231企业ID已建核验队列，已完成19家企业、15张独立图片；尚有27212家待核验。来源及品牌关系未确认的企业保留文字标识。详细出处见该目录verified.csv与registry.json；待补充顺序见pending.csv。

核验范围包括7-Eleven、A.O. Smith、ABB及三个逐项确认关系的中国企业、Aden、DEKRA、TCL、中兴、华为、宁德时代、平安银行、招商银行信用卡中心、比亚迪、讯飞、美的、隆基。图片不使用第三方热链，列表和详情完整展示、不拉伸；文件缺失或校验失败恢复文字占位。
