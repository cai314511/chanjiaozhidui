# 赛题规则逐条核查

依据：项目内《赛题规则.pdf》正文，页码均指PDF文件页码。规则给出了五类评审维度，没有规定各维度分值比例；企业可调能力权重属于业务模型参数。

| 外部模型与内容，第6页 | 模型输入身份泛化与规则扫描、输出标识检查，保留人工审核状态 | model_gateway、check_model_output | 事实与伦理人工审查；未接入第三方全类型内容审核服务 |
