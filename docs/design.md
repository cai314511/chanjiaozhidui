# 智链产教设计与数学模型

用户已确认：AI产品与金融科技两个核心行业；企业、学生、高校三端联动；沿用参考项目的视觉语言；通过服务端复用获授权的本地 DeepSeek 密钥。独立项目，本地交付。

## 业务与权限

企业发布岗位、动态调整能力权重、设置必要条件、薪资及培训资源，发布文字、语音与情景题；学生上传材料、设置偏好、参加测评、主动投递；企业同意后形成双向选择。高校仅按本校归属聚合培养缺口，不接收个体简历、成绩或面试原文。高校入校码绑定学校，少于5人的分组不显示能力统计。企业只访问主动投递且未撤回学生的授权画像和对应测评。学生可撤回投递，撤回立即收回企业端访问。

所有账号通过密码登录，服务端会话校验。三端切换为导航；身份权限来自登录会话。账号角色在注册后不能自行变更。学校主体为本地注册建立的组织，公开上线前需接入真实组织认证。

## 数学模型

模型版本 matching-1。每个岗位技能 i 的目标 r_i∈[1,5]，企业自定权重 w_i≥0，要求至少一个正权重。a_i=w_i/Σw。技能达标程度 u_i=min(1,s_i/r_i)，超额技能不抵消其他技能缺口。软性维度使用明确的题目与行为评分标准，不能通过音色、姓名或文字风格推断人格。

已核实证据决定可确认贡献。e_i=1 表示该岗位已完成企业复核的测评证据，否则为0。保守企业评分 E_L=100Σa_i e_i u_i；上界 E_U=100Σa_i[e_i u_i+(1-e_i)]。自述画像可给出暂定分 E_P=100Σa_i u_i（未知为0），但必须同时显示覆盖率 C=Σa_i e_i、上下界和待核实状态。上下界表示未核实信息的取值范围，不是统计置信区间。

学生对岗位的适合度 S 使用学生自定偏好权重：薪资达成率 min(1,岗位薪资上限/学生目标月薪)、城市一致、行业一致、工作方式一致、培养目标技能覆盖率。空集合表示没有该项偏好，对应效用为1；目标薪资为0表示无要求。所有权重非负且总和为正。

综合双向分 B(E,S)=2ES/(E+S)，两者均为0时取0。分别对企业评分上下界计算双向分上下界；暂定分只用于有提示的探索排序。必要条件逐项给出通过、未满足、待核实；不满足直接排除，待核实保留在待审核区。院校条件仅允许企业明确填写院校名称，学生背景为自述，待企业核验。必要能力等级来自企业复核测评。

修改权重会创建不可变版本，原始权重、标准化权重与评分明细随匹配结果返回。权重预览不保存；保存通过版本比较避免覆盖并发编辑。权重为0的技能不贡献分数或覆盖率，但必要条件仍执行。敏感性分析逐项增加10个百分点后重新标准化，显示分数变化。

企业招聘分配使用容量约束：仅双方主动选择、全部必要条件通过且能力核验证据完整的候选对进入整数优化，学生至多一个岗位、岗位不超名额，薪资上限×人数不超月度预算，培训成本与导师课时分别受企业总资源限制。分配结果是建议，不代替录用。

高校课程优化使用0/1整数规划，最大化加权技能缺口的覆盖收益。变量 x_j 表示是否选择方案j，覆盖变量 z_i 满足 z_i≤gap_i 且 z_i≤Σgain_ij x_j；约束总预算、学分、师资课时、实验室课时、学生学习课时与期限。边际收益饱和，重复课程不能重复计入已消除缺口。所有投入与能力增益是使用者录入的方案假设；输出为情景测算。优化失败明确报错。

## Agent 与资料

DeepSeek 通过官方 chat completions 接口进行结构化抽取、生成测评草稿、对回答给出行为证据建议及解释确定性结果。调度器先执行服务端授权工具，模型不能自行扩大数据范围；AI产出均为待确认。资料上传后先在本地提取，用户主动点击分析才发送必要正文；发送内容在页面可查看。题目评分草稿经企业逐项确认后才能进入已核实贡献。

资料支持 DOCX、PDF、TXT、CSV、XLSX；原始文件保留在私有目录，文档文本保留定位和SHA-256。扫描PDF无文本时明确提示。音频采用浏览器录制或上传，保存原始音频；浏览器支持时转写，转写文本由学生确认后提交，评分依据文本，原音频供企业复核。未配置语音识别服务时允许人工填写转写，不声称已自动识别。

下载中的产业、就业、政策压缩包不读取、不解压；数据目录提供导入工具及来源预览。完成后的ZIP只列出受支持成员，由用户选择文件接入，限制文件大小、数量和解压路径。真实产业证据与个人资料分开。无真实数据时显示空状态。

## 前端与验收

FastAPI + SQLite + 原生 HTML/CSS/JavaScript。复用卷草SVG，复刻米白、蓝金、磨砂卡片、跟随光效与抽屉交互；使用本项目名称、业务导航与自有图标。响应式布局，键盘可操作，支持减少动态效果偏好。

验收覆盖：权重变化逆转排序、必要条件不能被高分抵消、缺证据不能满分、上下界、零权重与无效数值、跨账号访问、撤回授权、学校聚合阈值、真实优化器与真实接口请求、本地浏览器交互。测试数据只在隔离测试数据库中使用。
