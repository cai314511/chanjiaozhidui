# Agent 模式导航与全站浮层交互

## 本地实现

三端共用新版助手。桌面面板顶部居中显示156px的WebGL水滴，手机为124px，模式菜单紧靠顶部。思考时增强液体表面流动、形变及波纹；倾听继续由实际输入音量驱动。低动态偏好和WebGL不可用时保留状态文字与输入能力。

学生提供聊天咨询、个人材料、面试复盘；企业提供聊天咨询、岗位草稿、测评建议；高校提供聊天咨询、培养建议。每项有用途说明和输入提示，支持键盘导航。切换模式保留未发送的问题；回复进行中、录音期间阻止切换，避免任务与输出错配。资料授权单独展开，不自动勾选。

聊天模式不再强制先调用材料工具。系统明确当前角色，可以回应寒暄、通用问题、用户主动描述的目标；只有需要个性化事实时才核对授权资料。缺少材料时给出准备建议及关键缺项，不用“无法分析用户请求”替代正常聊天。服务器缺密钥或API失败仍返回真实错误，不提供假回复。

全站浮层由统一交互模块协调：主弹窗、功能搜索、探索问卷及结果、Agent抽屉可点击外部关闭；点击内容和从内部拖拽到外部不会误关。手机侧栏和助手授权浮层也支持外部收起。普通功能页仍使用导航，点击空白不会离开业务页面。

电脑端消息输入（Agent、站内消息、语音面试的文字框）支持Enter发送、Shift+Enter换行，兼容中文输入法，不绕过录音和资料授权校验。手机软键盘保留换行。登录及其他表单保持浏览器原有提交行为，不把课程JSON或岗位描述的换行误当成发布动作。

通过外部关闭的普通表单文字草稿仅保存在当前页面内存，按原表单内容区分，切换账号清除。密码、文件和授权勾选不恢复；尚未提交的文件有重新选择提示。Agent保留问题；访谈转写按用户和面试会话区分，关闭停止录音及播放，重新进入同一会话可继续编辑。

真实本地免登录三端聊天成功，最新耗时学生2.03秒、企业3.16秒、高校1.58秒；在角色提示补充后核对企业和高校回复围绕各自任务。思考状态前后两张实际Canvas图像有连续像素变化；检查了1440×900及390×844布局。证据在 `runtime/agent-redesign-20261116/review-local-final.json` 及 `*-thinking.png`、`*-reply.png`、`*-mobile.png`。
