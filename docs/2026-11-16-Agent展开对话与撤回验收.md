# Agent 展开对话与问答撤回

三端共用弹性主展示区。输入新问题时切回水滴画面，发送后显示真实请求的思考动效；回复完成后自动切换为大面积聊天记录，不再让固定水滴区挤压输出。输入栏保持可用，“查看历史对话”可在输入或等待期间查看已存在的问答。桌面和手机均保留独立滚动、中文输入法与回车发送行为。

回复附复制、追问、撤回按钮。复制写入剪贴板，HTTP 环境使用浏览器复制能力并明确报告失败。追问引用选中的服务端问答，最多回溯六轮；每轮检查归属、投递和文档访问权限，旧资料失去授权后拒绝引用。前端传递记录标识，不接受任意客户端历史冒充授权记录。历史记录在重新打开页面后恢复；升级前未保存的问题正文不补造。

撤回范围经用户确认：删除该条问答及未保存草稿，保留已经人工确认保存的业务数据。服务端清除问答正文及结果，仅保留无正文的撤回标记，使重复撤回幂等，已撤回记录不会出现在历史接口中。前端删除同轮问题与回答，恢复剩余问答对应的草稿状态。已打开但未保存的画像恢复为保存版本，未保存岗位表单及其关闭草稿清除。已保存画像和岗位不回滚。服务端撤回失败时保留界面问答并提示原因。

- 相关回归 45 项全部通过；补充企业未保存岗位草稿撤回检查 1 项通过，共 46 项。覆盖三端切换、长回复、桌面与 390×844 浏览器、剪贴板内容、连续追问、刷新恢复、撤回失败、跨账号拒绝、已保存与未保存画像区别、岗位草稿、语音停止与 WebGL 降级等。
- 使用真实 DeepSeek、隔离数据库，三端各发送一条问题和一条引用追问，共六次实际调用均 HTTP 200，最新耗时 1.61—2.95 秒。随后逐端撤回第二轮，核对服务端仅剩第一轮记录。
- 真实调用结果与桌面、手机截图保存在 `runtime/agent-conversation-review/real-api-review.json`、`*-real-desktop.png`、`*-real-mobile.png`。界面故障测试中的模型与录音替身有单独标注，不用于声称真实声学识别通过。
