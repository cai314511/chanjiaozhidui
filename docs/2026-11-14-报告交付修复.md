# 高校报告交付修复（2026-11-14）

本次仅在本地实施，不包含提交、推送或部署。

## 报告状态与约束诊断

报告明确区分尚未测算、输入待补、当前约束下无可行方案、当前候选未产生改善、可行改善方案。没有成功改善方案时，候选留在“约束诊断”，不进入推荐课程，不生成调整后的课程清单。

高级决策诊断复用 `validate_program`，检查受保护课程、学分学时、先修关系及教师、实验室与预算约束。每个候选列出实际超限资源的需用量、上限与差额。简版优化按正收益判定改善，零缺口、零收益课程即使被求解器选中也不显示为改善推荐；每个候选的资源超限单独列示。

## 快照与变更

新的高级测算记录保存专业课程、动作与项目、预算资源、能力基线、情景假设、岗位证据、课程库和本校配置的指纹，并保存课程库快照。优化工作区保存工作区 ID/版本与课程库指纹和快照。报告比较对应工作区及输入版本，不把最新草稿替换进历史结果。

向导生成的高级方案同时关联工作区 ID 与实际输入摘要。导航步骤、结果和历史记录关联不改变该摘要；专业、目标、课程、资源、动作与高级情景输入变化会使报告过期。保存高级方案和执行 run 时均核对本校归属及摘要，过期输入返回 409，要求确认并生成新方案。

高级方案发生变化后，需要先查看变化类别，再明确确认生成新 run。旧版本令牌在计算前后均检查，输入已继续变化时返回 409。新记录关联原 run，原 run 保持原样。课程库或本校配置变化需要返回向导确认课程、资源和动作，再生成新方案，不能仅刷新指纹宣称已纳入变更。

历史记录未保存的课程库、本校配置版本显示“未记录”，不补造旧版本。

## 教学计划与阅读

报告读取已经确认的教学计划字段：原模块、新模块、明确填写的学时、先修、实施学期、项目考核、投入说明和实施里程碑。未确认或空白的字段显示待补；已删除按固定比例拆分学时和通用四年实施模板。四年预测仍只读取已保存的真实测算结果。

首屏展示计算状态、培养改善、重点调整和预算；主要说明文字至少 14px。明细与依据折叠。报告页为助手入口预留右侧 64px 安全栏，入口为可直接点击的 44px 固定按钮。

## 图文交付

顶部“导出图文报告 / PDF”打开独立打印窗口，固定点击时的当前情景和报告快照。Canvas 转换为静态 PNG，包含当前/调整后指标、四年逐年数据、资源表、课程建议、假设与来源。主页面随后切换情景不会改变已导出的报告。

打印前等待图片解码和字体就绪；通过浏览器打印保存 PDF。还可下载包含完整样式和内嵌图像的独立 HTML，离线打开后无需登录即可阅读和打印。浏览器预览沿用站点 CSP，通过 CSSOM 与事件绑定显示样式和打印操作；未修改站点安全策略。
