# 三维水滴语音界面

语音窗口独立采用纵向冷灰蓝布局。现有业务页面、转写接口、语音合成与授权规则继续使用。

Three.js 0.180.0 的官方发布文件放在 web/vendor/three，保留 MIT LICENSE；浏览器从本机加载，不依赖外部 CDN。渲染实现位于 water-orb.js，界面排列位于 voice-layout.js，样式位于 water-voice.css。

水体使用 MeshPhysicalMaterial：IOR 1.333、transmission 1、roughness 0.025、metalness 0、clearcoat 1。程序化摄影棚通过 PMREM 生成环境反射。GLSL 对三维表面施加低幅噪声，并重新计算曲面法线。透射路径执行入水与出水两次 Snell 折射，将出射光投影到场景背景平面采样，按传播距离计算吸收，并对三个颜色通道施加微弱折射差异。

出射交点采用近椭球几何近似；底部焦散采用近球体的双界面折射光束投射。它们是适合实时浏览器运行的光学近似，未实现多次内部反射、完整路径追踪或流体力学求解。纯净水使用很弱的吸收，避免通过不透明蒙版形成材质。

待机、监听、思考、播报分别影响运动速度、环流与扰动。监听和播报振幅来自现有 AudioContext 分析器，通过指数平滑传给渲染器。请求处理、播放开始和错误使用独立状态。手机限制像素比和几何细分；隐藏页面暂停渲染；关闭窗口销毁几何、材质、环境贴图和 WebGL 上下文。减少动态效果时固定形变和位移。

运行 tests/test_water_orb.py 检查真实 WebGL 编译、材质参数、五种组件状态、关闭释放和移动布局；tests/test_streaming_voice.py 使用本地中文合成音频验证真实录音与转写。组件状态测试不代表真人麦克风验收。

参考：[MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)、[PMREMGenerator](https://threejs.org/docs/pages/PMREMGenerator.html)。
