## 核对项目

| 字典要求 | 原实现 | 修正及验收口径 |
| --- | --- | --- |
| UTF-8 BOM、标准 CSV、长文本（PDF 第8页） | 已用 DictReader，未放宽字段长度 | 统一读取器，字段上限16×1024×1024字符，空行及多行正文仍记录物理起始行，畸形行明确报错 |
| 按列名区分来源平台与来源（第4–6页） | 已按字段名读取 | 保留；覆盖缺来源平台、不同列序及两种来源字段的测试 |
| 股票代码补足6位，代码保持字符串（第4、8页） | 股票未参与处理 | 清洗股票字段为6位字符串；信用代码、行政区划不做数值转换 |
| 日期 trim、浮点年份转整数（第4–6、8页） | 日期截前10字符，未处理年份 | 严格日历日期；年份整数化；冲突采用有效日期年份并记异常，不从年份编造月份 |
| 零/空薪资排除（第4、8页） | 已排除零、空、反向、非有限区间 | 零和空统一为未知报价；不同单边报价不误合并；不折算成就业收入 |
| 招聘人数清洗（第4、6、8页） | 所有研究公告人数均为 null | 正整数及“N人”解析；空、若干、区间不补人数；仅为公告拟招人数 |
| 跨表学历、经验、类别映射（第8页） | 保留自由文本，未统一 | 确定同义值映射；未知值保留；工作性质与行业/职能类别分开 |
| 重复公告 | 部分入口忽略学历、经验和人数差异 | 三入口共享摘要规则，要求或具体工作地点不同的公告保留，真正重复跨文件合并 |
| 上市公司行业（第4页） | 部分说明称企业原始行业 | 明确为关联上市公司行业参考，不能认定子公司法人行业或GB/T编码 |
| 工商数据（第7–8页） | 未接入 | 继续不纳入统计，不新增个体工商户；不以UID或名称替代信用代码去重，不推定资本单位 |
| 就业报告、产业指南、政策（第3页） | 保留出处、缺失样本和不可提取状态 | 保持；字典抽样比例不能写成全时期统计；政策文本不转换成招聘人数 |
