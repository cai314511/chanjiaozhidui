# 产教智对

面向 AI 产品与金融科技的企业、学生、高校三端系统，围绕岗位技能证据开展双向匹配、测评、选择与资源约束下的培养决策。

## 本地使用

预览地址：[http://127.0.0.1:8765](http://127.0.0.1:8765)。首次进入可以注册企业、学生或高校账号，各身份使用独立账号。正式数据库初始为空，浏览器验收使用独立数据库。

在本目录打开 PowerShell，运行：

```powershell
.\.venv\Scripts\python.exe scripts/serve.py --background
```

停止本项目服务：

```powershell
.\.venv\Scripts\python.exe scripts/serve.py --stop
```

修改后先停止再启动。启动器检查健康接口，日志和进程记录在 `runtime/server/`，服务仅监听本机。停止前核对进程命令，避免终止其他程序。

新环境使用 Python 3.11 及以上，建立 `.venv` 并安装 `requirements.txt`。本次环境复用了本机已有 Python 包，其余依赖仅安装到本项目虚拟环境。浏览器测试另需 Playwright 和本机 Edge。

## 三端操作

企业：上传JD或填写岗位，确认必要条件、薪资和招聘资源；通过“招聘偏好”选择一般关注、重点关注或优先考虑，后台更新匹配结果。候选人投递后查看授权画像、作品与资料，复核测评回答，进入预设、AI或真人面试会话。招聘资源分配根据双方选择、证据状态和资源上限计算建议。

学生：上传简历、成绩单、个人网站正文或作品，或者从语音讲述开始。系统整理的个人介绍需确认后保存。查看总体匹配度，选择授权文档与作品后投递；支持文字、语音或工作场景测评。学习方案优化同时检查预算、学习课时与期限。

高校：注册时生成入校码，由学生在画像中自愿填写。高校只查看本校聚合数据，每项技能至少5人有记录后展示。依据岗位要求和自述培养能力的差异，录入课程、实践或专业方向方案，优化预算、学分、师资、实验室、学生时间和期限约束下的组合。汇总描述站内样本，不代表全校或行业统计。

岗位内容变更会生成新版本，并要求双方重新选择、重新核实。改变题干、评分标准或关联技能时，旧回答从当前测评移除并留存在历史记录中。仅调整能力权重保留已有有效测评。

## 数学模型

模型版本 `matching-1`，完整定义见 `docs/design.md`，实现见 `backend/matching.py`。

高校专业调整模型为 `decision-2`，定义见 [专业调整数学模型](docs/专业调整数学模型.md)，规则对应和交付状态见 [赛题规则逐条核查](docs/赛题规则逐条核查.md)。

1. 必要条件逐项检查专业、院校、语言、必要能力及学生设定的薪资和城市底线，返回通过、未满足或待核实。
2. 企业为每项能力设置0–100的原始权重，至少一项大于零。令 `a_i = w_i / sum(w)`，目标等级为 `r_i`，能力等级为 `s_i`，达标程度 `u_i = min(1, s_i/r_i)`。超额能力不会抵消其他缺口。
3. 自述能力产生暂定分。已经企业复核的测评证据产生可确认贡献，未核实能力的贡献给出下界0、上界1。系统同时显示评分上下界及加权证据覆盖率；这个范围表示信息缺失范围。
4. 学生偏好分单独计算薪资、城市、行业、工作方式和成长目标。综合双向分为 `2ES/(E+S)`，双方均为零时取零。必要条件不满足的组合被排除，待核实组合不能进入正式分配。
5. 权重预览和保存均在服务端重新计算。保存采用乐观版本检查，历史版本保持不变。敏感性分析逐项增加原总权重的10%并重新归一化，展示暂定分变化。
6. 招聘分配采用整数规划，学生至多分配一个岗位，同时限制岗位名额、月度薪资总额、培训费用及导师课时。
7. 培养与学习方案采用混合整数规划，最大化加权能力缺口改善。收益按缺口饱和计算，避免重复覆盖带来的收益高估。候选方案按可并行执行的独立方案建模，每项完成时间不得超过期限；成本、课时和预期能力增益由使用者录入并作为情景假设保存。

正式分配逐项检查所有正权重能力的核验状态，显示分数的四舍五入不会改变资格。权重为零的必要能力仍参与必要条件检查。

## DeepSeek 与资料

服务端优先读取 `DEEPSEEK_API_KEY` 环境变量或本项目 `.env`，随后按已获得的授权读取 `../比赛/金融人工智能竞赛/.env` 中的 `FINREPORT_LLM_API_KEY`。密钥不会复制到前端、日志或输出。可参考 `.env.example` 配置独立密钥。

使用官方 [Chat Completions 接口](https://api-docs.deepseek.com/api/create-chat-completion/)，默认模型 `deepseek-flash`。调度器按岗位解析、个人画像、测评辅助、培养建议等任务组织工具调用；工具只能读取当前账号已获授权的材料和确定性计算结果。AI生成的岗位或画像草稿先填入表单，人工检查保存；AI评分建议需要企业引用已回答题目进行复核。

上传资料先在本地提取，支持 TXT、MD、CSV、DOCX、PDF、XLSX，每份最多12MB、50万字符。CSV/TXT使用UTF-8。正文保留页码、段落或表格行位置及SHA-256；扫描PDF需要先做OCR。点击助手发送时会说明所发送的画像与测评内容，文档正文需要额外勾选授权。

桌面产业、就业、政策压缩包下载完成后，在资料库查看成员并选择导入。系统不会读取下载中的文件，也不会一次性展开整个压缩包。超过12MB的成员需要先拆分成适合分析的资料。导入的是所选文件，尚未导入的数据不会参与评分或形成产业趋势结论。

语音使用本机 Whisper 识别与 Windows 中文 SAPI 合成，支持分段转写、水滴面试、预设问题及真人会话入口。转写可以修改；AI面试需要确认将转写发送给 DeepSeek。系统依据实际经历和行为证据整理建议，不从音色推断人格。配置、运行条件和验证范围见[本地语音与交互说明](docs/本地语音与交互说明.md)。

## 权限与数据

账号使用scrypt保存密码摘要，12小时会话保存在HttpOnly与SameSite Cookie。所有资料与业务接口执行服务端身份检查；跨来源写请求会被拒绝。数据和原文件保存在 `data/private/`，不可通过静态地址访问。

投递是企业查看学生画像、测评和所选资料的授权来源。撤回后重新检查权限，企业端历史AI分析也随来源授权失效。测评、画像和岗位变更采用事务及版本检查，原始回答与复核依据保留为历史快照。高校入校码不会出现在企业收到的学生画像中。

当前为本机运行，企业与高校组织身份通过本地注册建立，尚未接入外部实名或组织认证。

## 验证

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe scripts/check_agent.py
```

第一条覆盖算法、权限、证据版本、并发及真实Edge浏览器操作。测试资料与账号写入 `runtime/` 下独立数据库，不使用正式资料。第二条会消耗少量API额度，以不含个人资料的问题验证真实模型与工具调用，结果保存为 `outputs/agent-verification.json`。

源文件分工：`backend/` 为服务、计算、存储、解析与模型调用；`web/` 为三端页面和交互；`tests/` 为可复用验证；`scripts/` 为启动和真实模型验证。原有比赛资料保持原状。

## 参赛研究工作流

使用高校账号进入“产业资料管理”，先登记来源、采集时间、获取方式、许可和脱敏审核声明。官方数据集与许可公开数据均需保存真实依据。招聘发布时间转为月份，薪资采用人民币月薪区间；就业平均起薪附至少5个样本。原始单位不同的资料须先记录换算依据，不能直接改列名冒充同一单位。

结构化JSON、CSV或XLSX按下载的字段规范导入。`skills`为包含`name/level/weight`的数组，CSV/XLSX单元格使用JSON数组文本。等级必须有抽取或人工审核依据，不能为了通过字段校验补默认分数。完全重复记录自动去除，内容相同但标识不同的招聘记录保留并标记复核。历史年度不会累加为当前年度需求。

“专业调整决策”提供空白填写模板和字段规范。文件包含`program`和`actions`：当前培养方案、能力评估证据、硬约束、当前按岗位类别归并的方向人数、拟设方向和配套课程、匿名意愿成绩分组，以及候选课程动作。分组的成绩是最低成绩或成绩区间下界，组内成员具有相同意愿，不能用平均分代表所有人通过门槛。

填写三种情景、招生参数、实施延迟和假设后运行。系统输出三维差距、课程变动、分流、四年反事实与情景、风险及逐轮反思。缺少核实年度招聘人数、市场可比范围或能力证据时，相关结果标记缺失。系数没有可靠依据时保持为0，避免凭空声称就业或薪资改善。

独立评测来源只验证已经固定的方案，不能参与课程组合生成。改动记录编号仍不能把相同内容改成独立样本。官方标准评测内容尚需下载完成后核对，并按其真实指标检验。

高校账号可以进入“公开演示模式”，收起个人业务资料页面并泛化账号显示，助手入口关闭。模式在当前浏览器页签刷新后保持，退出账号时清除。它用于控制屏幕展示，服务端访问权限仍由登录身份和数据归属决定。研究结果另执行小样本互补抑制，演示前仍需人工检查案例正文。

## 本地数据处理与复算

使用`scripts/research.py`在本地执行，不会调用外部API。支持结构化JSON、CSV、XLSX和显式字段映射；规范化包保留来源、处理摘要与SHA-256。

```powershell
.\.venv\Scripts\python.exe scripts/research.py normalize --source data/source.json --kind recruitment --input data/recruitment.csv --mapping data/fields.json --output outputs/recruitment-clean.json
.\.venv\Scripts\python.exe scripts/research.py normalize --source data/source.json --kind employment --input data/employment.xlsx --output outputs/employment-clean.json
.\.venv\Scripts\python.exe scripts/research.py analyze --case data/case.json --recruitment outputs/recruitment-clean.json --employment outputs/employment-clean.json --output outputs/research
```

以上路径是使用格式，需要先准备真实来源和资料文件。`fields.json`是原字段名到规范字段名的映射，不做未经声明的单位换算。单批最多20000条，大型来源按完整记录和统计范围拆分，不得把部分样本称为完整年度需求。本地复算的数据由命令行文件指定，在线数据标识只用于记录原案例引用。

工作台支持导出完整JSON、课程CSV和报告Markdown正文。报告PDF、≤5分钟视频、答辩PPT需按赛题要求分别制作和验收；外网API须在现场使用前向主办方报备、联调。本地引擎支持当场重算，缓存不作为现场演示已通过的证明。
