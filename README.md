# 智链产教

面向多行业的企业、学生、高校三端系统，围绕兴趣探索、企业赛道、岗位技能证据开展双向匹配、测评、选择与资源约束下的培养决策。

## 三端演示空间与企业招聘工作台

未登录首页点击“免登录体验三端”，无需注册即可切换学生、企业和高校。每个浏览器对应独立的SQLite、文件和会话，退出后保留7天，可重置体验；正式登录Cookie不被替换，数据不会写入正式数据库。人物、作品与业务记录独立编写，不读取本机真实简历。市场参考数据来自可随版本部署的比赛聚合包。

企业首页展示本公司岗位、投递、候选人和双向意向，岗位支持草稿、招聘中、暂停及结束状态。候选人和学生主页提供授权简历、作品、收藏、联系与私信；学生在消息中心回复。权限由服务端按企业、投递授权及会话参与人校验。

部署和验证步骤见[docs/aws-update.md](docs/aws-update.md)。本地代码不会自动更新AWS，也不会把本机`.env`、真实账号库或用户资料上传。DeepSeek可执行`python scripts/check_deepseek.py --call`验证实际调用；健康接口只反映配置是否存在。

## 探索、收藏与学生主页

高校首页为“需求研判中心”，以本地Apache ECharts 6.0.0的Canvas图表展示需求趋势、产业结构、技能频次、本校能力、课程覆盖、产业技能网络和匿名学生目标。赛道与城市联动筛选；前台每60秒刷新平台岗位与本校数据，历史观察期单独标注，不作为实时全市场缺员人数。缺少等级、课程映射或足够本校样本时显示具体缺项。

全量需求聚合：`.venv/Scripts/python.exe scripts/import_demand.py --store-root data/private`。扫描两份2026CSV按公告去重，不用企业少量展示样本推算市场。写入前自动备份，仅更新独立需求记录。

高校可导入课程、培养方案和教务系统课程表。CSV/XLSX字段为“课程代码、课程名称、学分、总学时、能力标签”（标签用分号分隔）；JSON支持courses或program.courses。PDF/DOCX保存为参考正文。各校目录独立，重复文档导入幂等。培养优化可采用有依据的本校能力差距及课程库候选；原总学时仅作旁注，新增学习、师资、实验室投入与能力增益由教师确认。

探索首页提供可输入的赛道下拉搜索，按企业、赛道和岗位关键词检索；语音在本机转写。学生首次进入会弹出可跳过的三步探索卡片，以选项及文字/语音补充整理兴趣，并从当前本地目录给出探索建议，之后可点“还没想好？帮我探索”重新开始。已取消全站卡片放大与底部模块缩略条。

企业注册时可多选或自填赛道，已有企业在“公司与赛道设置”补充。岗位所属行业已开放为文本赛道，历史岗位版本继续保留。全行业目录从两份2026年CSV整理27231家标准化企业；缺少行业证据的企业保留“未分类”，仍可按企业名或完整岗位标题检索。目录只展示每企业近期历史公告样本，与平台注册企业及实际发布岗位分别标识。

更新全行业目录：`.venv/Scripts/python.exe scripts/import_market.py --store-root data/private`，输入默认复用`runtime/competition-input/`的两份CSV（可先运行`import_competition.py`提取），或用`--csv`指定文件。执行前自动备份，随后只更新共享目录实体；不会创建真实企业账号、替企业发布岗位。只读赛道标签允许注册前查询，企业和岗位详情需登录。

学生在“我的”收藏企业或赛道，动态仅显示相应企业或赛道实际在平台发布的岗位。也可编辑展示名、学历、专业、背景、兴趣特长、个人网站，上传头像、简历和作品视频。草稿仅自己可见；点击“保存并发布主页”后，选定信息及勾选资料才对站内学生、企业、高校可见，并在“学生主页”目录展示。公开链接格式为`/?student=账号ID`，访问仍需登录。修改草稿不改变当前公开快照；撤回后主页、头像及资料的主页授权立即失效，其他独立投递授权继续按原规则检查。头像限制3MB，校验真实图片并转换PNG清除元数据；网站链接以新窗口打开。

## 管理员与初始资料

首页右上角提供“管理员入口”。管理员登录后，可以进入学生、高校及企业工作空间，顶部显示当前账号，并提供“切换工作空间”和“返回管理入口”。切换保留管理员登录会话；退出会结束整个登录。公开注册不能创建管理员。

本机初始化入口为 `.venv/Scripts/python.exe scripts/initialize.py`。执行前自动备份现有数据库并检查备份完整性。初始化包含华辰财经大学、青岚理工大学、江川应用技术大学及每校5名学生，学生有画像和简历，高校有课程、方向、分流与培养配置；企业工作空间没有预置岗位和招聘资料。重复执行保留已有资料。

管理员账号为 `admin`，生成的密码和其他账号信息仅存放在 `data/private/account-access.json`，不进入版本控制或前端资源。保管好本机文件。管理员切换与工作空间写操作分别记录管理员主体和目标账号；普通用户继续受原有账号、学校和投递授权限制。

在本目录打开 PowerShell，运行：

```powershell
.\.venv\Scripts\python.exe scripts/serve.py --background
```

停止本项目服务：

```powershell
.\.venv\Scripts\python.exe scripts/serve.py --stop
```

修改后先停止再启动。启动器检查健康接口，日志和进程记录在 `runtime/server/`，服务仅监听本机。停止前核对进程命令，避免终止其他程序。

新环境使用 Python 3.11 及以上，建立 `.venv` 并安装 `requirements.txt`。本次环境复用了本机已有 Python 包，其余依赖仅安装到本项目虚拟环境。浏览器测试另需 Playwright 和本机 Edge。

## 三端操作

登录学生、企业或高校账号后，右下角助手入口显示对应角色，点击打开原有智能助手和语音水滴。首页右侧的角色先探头出场，再每3秒切换九种姿态；页面隐藏或离开首页时停止，系统启用减少动态效果时显示静态形象。透明图集及来源说明位于 `web/mascots/`，原始海报保留在 `Assets/agent/`。

未登录首页也展示精灵：顶部介绍区从三端共27种姿态中每3秒随机选择一个，右下角在三端主形象间平滑切换，均避免连续重复。点击访客助手入口提示登录；登录后切换为本端固定角色。单个图集加载失败时，访客仍可展示其余可用形象。

企业：上传JD或填写岗位，确认必要条件、薪资和招聘资源；通过“招聘偏好”选择一般关注、重点关注或优先考虑，后台更新匹配结果。候选人投递后查看授权画像、作品与资料，复核测评回答，进入预设、AI或真人面试会话。招聘资源分配根据双方选择、证据状态和资源上限计算建议。

学生：上传简历、成绩单、个人网站正文或作品，或者从语音讲述开始。系统整理的个人介绍需确认后保存。查看总体匹配度，选择授权文档与作品后投递；支持文字、语音或工作场景测评。学习方案优化同时检查预算、学习课时与期限。

高校：注册时生成入校码，由学生在画像中自愿填写。高校只查看本校聚合数据，每项技能至少5人有记录后展示。依据岗位要求和自述培养能力的差异，录入课程、实践或专业方向方案，优化预算、学分、师资、实验室、学生时间和期限约束下的组合。汇总描述站内样本，不代表全校或行业统计。

高校首页为“需求研判中心”，使用本地 ECharts Canvas 展示招聘月度趋势、产业结构、技能需求、能力雷达、课程覆盖、产业技能网络及学生目标。可按赛道和城市联动筛选；页面可见时每60秒读取平台岗位和本校汇总，也可手动刷新。离开页面后释放图表与刷新器。历史招聘公告与当前平台岗位分开统计，公告条数不作为空缺人数，能力差距仅在岗位目标和本校样本均有效时计算。

“上传本校课程”“上传培养方案”“导入教务系统课程表”替代高校页面的个人网站和作品入口。课程支持UTF-8 CSV、XLSX及JSON，字段为课程代码、课程名称、学分、总学时、能力标签；标签多项用分号分隔。教务系统先导出表格再上传，无需提供账号密码。每份最多12MB，每批最多2000门，同校相同课程代码更新，其他课程保留。PDF、DOCX及文本作为本校培养依据保存。进入培养方案优化后，先采用需求研判中的本校能力差距，再从本校课程库选择候选方案；资源投入和预期能力改善由教务老师核对后计算并保存。

历史需求聚合可单独重建，导入前自动备份数据库并检查备份完整性，不调用外部模型：

```powershell
.\.venv\Scripts\python.exe scripts/import_demand.py
```

默认读取 `runtime/competition-input/上市公司招聘数据2026.csv` 和 `应届生招聘大数据2026.csv`；也可重复使用 `--csv` 指定文件，或使用 `--store-root` 指定隔离数据目录。图表运行库及许可证保存在 `web/vendor/echarts/`。

岗位内容变更会生成新版本，并要求双方重新选择、重新核实。改变题干、评分标准或关联技能时，旧回答从当前测评移除并留存在历史记录中。仅调整能力权重保留已有有效测评。

## 数学模型

模型版本 `matching-1`，完整定义见 `docs/design.md`，实现见 `backend/matching.py`。

高校专业调整模型为 `decision-2`，定义见 [专业调整数学模型](docs/专业调整数学模型.md)，规则对应和交付状态见 [赛题规则逐条核查](docs/赛题规则逐条核查.md)。

1. 必要条件逐项检查专业、院校、语言、必要能力及学生设定的薪资和城市底线，返回通过、未满足或待核实。
2. 企业为每项能力设置0–100的原始权重，至少一项大于零。令 `a_i = w_i / sum(w)`，目标等级为 `r_i`，能力等级为 `s_i`，达标程度 `u_i = min(1, s_i/r_i)`。超额能力不会抵消其他缺口。
3. 自述能力产生暂定分。已经企业复核的测评证据产生可确认贡献，未核实能力的贡献给出下界0、上界1。系统同时显示评分上下界及加权证据覆盖率；这个范围表示信息缺失范围。
4. 学生偏好分单独计算薪资、城市、行业、工作方式和成长目标。综合双向分为 `2ES/(E+S)`，双方均为零时取零。必要条件不满足的组合被排除，待核实组合不能进入正式分配。
5. 权重预览和保存均在服务端重新计算。保存采用乐观版本检查，历史版本保持不变。敏感性分析逐项增加原总权重的10%并重新归一化，展示暂定分变化。
6. 招聘分配采用整数规划，学生至多分配一个岗位，同时限制岗位名额、月度薪资总额、培训费用及导师课时。
7. 培养与学习方案采用混合整数规划，最大化加权能力缺口改善。收益按缺口饱和计算，避免重复覆盖带来的收益高估。候选方案按可并行执行的独立方案建模，每项完成时间不得超过期限；成本、课时和预期能力增益由使用者录入并作为情景假设保存。

正式分配逐项检查所有正权重能力的核验状态，显示分数的四舍五入不会改变资格。权重为零的必要能力仍参与必要条件检查。

## DeepSeek 与资料

服务端优先读取 `DEEPSEEK_API_KEY` 环境变量或本项目 `.env`，随后按已获得的授权读取 `../比赛/金融人工智能竞赛/.env` 中的 `FINREPORT_LLM_API_KEY`。密钥不会复制到前端、日志或输出。可参考 `.env.example` 配置独立密钥。

使用官方 [Chat Completions 接口](https://api-docs.deepseek.com/api/create-chat-completion/)，默认模型 `deepseek-flash`。调度器按岗位解析、个人画像、测评辅助、培养建议等任务组织工具调用；工具只能读取当前账号已获授权的材料和确定性计算结果。AI生成的岗位或画像草稿先填入表单，人工检查保存；AI评分建议需要企业引用已回答题目进行复核。

上传资料先在本地提取，支持 TXT、MD、CSV、DOCX、PDF、XLSX，每份最多12MB、50万字符。CSV/TXT使用UTF-8。正文保留页码、段落或表格行位置及SHA-256；扫描PDF需要先做OCR。点击助手发送时会说明所发送的画像与测评内容，文档正文需要额外勾选授权。

“产业数据支撑”展示本机“比赛数据”目录中已处理的招聘、产业指南、就业报告和政策资料，学生、企业及高校登录后均可查看。首页和高校产业资料管理提供入口。可按城市、方向和关键词检索历史岗位，并查看原CSV行号；文献按关键词定位PDF页码或Word段落。历史公告与企业正式发布的招聘分开，不能直接投递。

本地更新资料使用以下命令，需本机7-Zip（可通过`--seven-zip`指定路径）：

```powershell
.\.venv\Scripts\python.exe scripts/import_competition.py
```

脚本只提取两套年份RAR的2026年CSV，读取全文件后按岗位标题与金融行业技术岗位规则筛选。同企业、同原始发布日期且脱敏岗位内容相同才合并，保留跨包出处；原始企业和完整日期只参与内部摘要，页面按月份展示。技能只统计正文提及，不生成能力等级。薪资指标为有效人民币月薪区间中点的中位数，不代表实际毕业收入。公告条数不作为核实招聘人数；缺失人数、能力等级和本校就业样本时，不将这些资料强行转换为培养模型输入。

本次还接入30份省级产业指南、2023—2026版就业报告及12份重点地区规划。汇编中的观点保留来源表述；2025版就业报告文字编码异常，已登记指纹并标明待OCR，广东规划含扫描页，按实际可提取部分展示。PDF使用PyMuPDF本地解析。工商分卷涉及企业与联系人明细，未纳入本轮展示。原始文件留在`比赛数据/`；导入前数据库备份到`data/private/backups/`并检查完整性，处理清单在`outputs/competition-import/manifest.json`。重复导入只更新专属共享证据记录，保留用户业务。

个人资料库也支持选择导入桌面ZIP中的单个文件，不会读取下载中的文件。超过12MB的上传材料需按实际内容拆分。共享研究证据通过登录后的只读接口展示，原始文件、数据库和账号密码不通过静态地址访问。

语音使用本机 Whisper 识别与 Windows 中文 SAPI 合成，支持分段转写、水滴面试、预设问题及真人会话入口。转写可以修改；AI面试需要确认将转写发送给 DeepSeek。系统依据实际经历和行为证据整理建议，不从音色推断人格。配置、运行条件和验证范围见[本地语音与交互说明](docs/本地语音与交互说明.md)。

## 权限与数据

账号使用scrypt保存密码摘要，12小时会话保存在HttpOnly与SameSite Cookie。所有资料与业务接口执行服务端身份检查；跨来源写请求会被拒绝。数据和原文件保存在 `data/private/`，不可通过静态地址访问。

投递是企业查看学生画像、测评和所选资料的授权来源。撤回后重新检查权限，企业端历史AI分析也随来源授权失效。测评、画像和岗位变更采用事务及版本检查，原始回答与复核依据保留为历史快照。高校入校码不会出现在企业收到的学生画像中。

当前为本机运行，企业与高校组织身份通过本地注册建立，尚未接入外部实名或组织认证。

## 验证

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe scripts/check_agent.py
```

第一条覆盖算法、权限、证据版本、并发及真实Edge浏览器操作。测试资料与账号写入 `runtime/` 下独立数据库，不使用正式资料。第二条会消耗少量API额度，以不含个人资料的问题验证真实模型与工具调用，结果保存为 `outputs/agent-verification.json`。

源文件分工：`backend/` 为服务、计算、存储、解析与模型调用；`web/` 为三端页面和交互；`tests/` 为可复用验证；`scripts/` 为启动和真实模型验证。原有比赛资料保持原状。

## Agent水滴与本地企业商标

三端右下角助手共用Three.js水滴，录音时随音量响应，转写先供用户编辑，确认提交后进入思考状态。关闭助手或退出身份会停止录音并释放渲染，页面隐藏会暂停动画、停止助手录音；减少动态效果偏好与WebGL静态降级不影响文字问答。原“语音讲述”入口保留。

企业商标保存在`Assets/company-logos/`，由`/api/company-logos/{company_id}`独立提供已核验PNG，不使用外部图片热链。`registry.json`记录企业ID、品牌、已确认名称、官方出处、图像SHA-256及核验状态；`verified-sources.json`保存本批官方资源清单。`pending_queue`为尚未核验的目录，缺图或文件校验失败时显示企业文字。

维护者先人工核实官网图片与企业品牌关系，再补充来源清单，使用项目虚拟环境执行`scripts/prepare_company_logos.py --manifest Assets/company-logos/verified-sources.json --brand "品牌名称"`下载。可先用`--inspect https://企业官网/`检查候选地址，候选地址不会自动成为已核验商标。`--initialize`从本地市场目录补充待核验ID，不修改企业或用户数据库。审核时以注册表实际verified数量为准，不将全量排队称为全量商标核验完成。

## 参赛研究工作流

使用高校账号进入“产业资料管理”，先登记来源、采集时间、获取方式、许可和脱敏审核声明。官方数据集与许可公开数据均需保存真实依据。招聘发布时间转为月份，薪资采用人民币月薪区间；就业平均起薪附至少5个样本。原始单位不同的资料须先记录换算依据，不能直接改列名冒充同一单位。

结构化JSON、CSV或XLSX按下载的字段规范导入。`skills`为包含`name/level/weight`的数组，CSV/XLSX单元格使用JSON数组文本。等级必须有抽取或人工审核依据，不能为了通过字段校验补默认分数。完全重复记录自动去除，内容相同但标识不同的招聘记录保留并标记复核。历史年度不会累加为当前年度需求。

“专业调整决策”提供空白填写模板和字段规范。文件包含`program`和`actions`：当前培养方案、能力评估证据、硬约束、当前按岗位类别归并的方向人数、拟设方向和配套课程、匿名意愿成绩分组，以及候选课程动作。分组的成绩是最低成绩或成绩区间下界，组内成员具有相同意愿，不能用平均分代表所有人通过门槛。

填写三种情景、招生参数、实施延迟和假设后运行。系统输出三维差距、课程变动、分流、四年反事实与情景、风险及逐轮反思。缺少核实年度招聘人数、市场可比范围或能力证据时，相关结果标记缺失。系数没有可靠依据时保持为0，避免凭空声称就业或薪资改善。

独立评测来源只验证已经固定的方案，不能参与课程组合生成。改动记录编号仍不能把相同内容改成独立样本。官方标准评测内容尚需下载完成后核对，并按其真实指标检验。

高校账号可以进入“公开演示模式”，收起个人业务资料页面并泛化账号显示，助手入口关闭。模式在当前浏览器页签刷新后保持，退出账号时清除。它用于控制屏幕展示，服务端访问权限仍由登录身份和数据归属决定。研究结果另执行小样本互补抑制，演示前仍需人工检查案例正文。

## 本地数据处理与复算

使用`scripts/research.py`在本地执行，不会调用外部API。支持结构化JSON、CSV、XLSX和显式字段映射；规范化包保留来源、处理摘要与SHA-256。

```powershell
.\.venv\Scripts\python.exe scripts/research.py normalize --source data/source.json --kind recruitment --input data/recruitment.csv --mapping data/fields.json --output outputs/recruitment-clean.json
.\.venv\Scripts\python.exe scripts/research.py normalize --source data/source.json --kind employment --input data/employment.xlsx --output outputs/employment-clean.json
.\.venv\Scripts\python.exe scripts/research.py analyze --case data/case.json --recruitment outputs/recruitment-clean.json --employment outputs/employment-clean.json --output outputs/research
```

以上路径是使用格式，需要先准备真实来源和资料文件。`fields.json`是原字段名到规范字段名的映射，不做未经声明的单位换算。单批最多20000条，大型来源按完整记录和统计范围拆分，不得把部分样本称为完整年度需求。本地复算的数据由命令行文件指定，在线数据标识只用于记录原案例引用。

工作台支持导出完整JSON、课程CSV和报告Markdown正文。报告PDF、≤5分钟视频、答辩PPT需按赛题要求分别制作和验收；外网API须在现场使用前向主办方报备、联调。本地引擎支持当场重算，缓存不作为现场演示已通过的证明。
