# 部署参考数据

`reference.json.gz`是已有比赛资料处理流程生成的三类聚合：全行业目录、需求观察和产业证据。它不包含正式用户表、登录会话、密钥、简历或用户上传的文件。

应用首次启动会为缺少这些记录的正式数据库补齐参考资料，已有同ID记录不会被覆盖。演示空间使用这些市场参考资料，人物、公司业务、投递、对话及校内培养方案由独立初始化逻辑编写；两者不混为实证数据。

更新参考包使用项目虚拟环境执行 `scripts/prepare_demo_reference.py`。该脚本只读取本机已导入数据库中的固定ID及固定归属，不扫描私人文件目录。

参考包须与代码一同部署。运行数据位于`data/private/`，禁止将该目录加入Git或覆盖现有云端持久数据。
